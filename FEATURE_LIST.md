# Feature list (reference for talks & planning)

Use this doc when discussing or prioritizing features. Each item is a single reference point you can point to in talks.

---

## 1. Product-page email capture (lead magnet)

**Goal:** Collect emails on product pages by offering a free, problem-solving download.

**Mechanism:**
- On each product page, offer a **free download** in exchange for email.
- The download must **solve the main problem** that the product addresses (so it’s relevant and valuable).
- Format options (pick one or combine):
  - **Brochure** (PDF) – e.g. “Complete guide to [topic]”
  - **Infographic** (PDF/image) – quick-reference, visual summary
  - **Half-and-half** – one side brochure, one side infographic in a single PDF

**Why it works:** Visitor gets immediate value; we get a qualified lead (they’re already on a product page) and permission to email.

**Reference phrase for talks:**  
*“Product-page lead magnet: free download (brochure and/or infographic) that solves the main problem, in exchange for email.”*

---

## 2. AI voice chat button (talk, not just type)

**Goal:** A chat button that opens an **AI voice conversation** – user talks, AI talks back (voice-to-voice), not just text chat.

**Mechanism:**
- Site has a **chat button** (e.g. floating button) that opens a voice chat interface.
- User speaks; AI responds with **voice** (spoken reply), so it’s a real back-and-forth conversation.
- Can still support text as fallback or alongside voice (type or talk).

**Why it matters:** More natural for many users, higher engagement, feels like talking to support or a guide.

**Reference phrase for talks:**  
*“Chat button that’s AI voice – talk back and forth, not just typing.”*

**Companion character (Grok-style):**  
- Like **Grok companions**: a **fun, talking, animated game character** (mascot) that does the voice chat – more personality, more engaging than a plain chat bubble.
- **Tradeoff:** Animated character (sprites, reactions, maybe lip-sync) can **slow the page** or increase bundle size. Mitigate with: load the character UI only when the user opens chat (lazy load), use lightweight assets, or offer a “simple mode” (voice only, no character) for performance.

**Reference phrase for talks:**  
*“Grok-style companion – fun talking animated character, but we have to watch page speed.”*
