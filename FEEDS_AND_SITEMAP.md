# Feeds and sitemap (SCV2)

## Sitemap (XML) – up to date

- **URL:** `https://www.successchemistry.com/sitemap.xml` (or your `NEXT_PUBLIC_SITE_URL`)
- **Generated by:** `src/app/sitemap.ts` (dynamic, no static file)
- **Includes:** Home, store, cart, contact, policy pages, blog index, every blog post, **every product** (`/product/{slug}`), product markdown pages (`/product-pages/{slug}.md`), and the Google Shopping feed URL.
- **Status:** Always current with the app; no manual XML to maintain.

---

## Google Shopping / Merchant Center feed

- **URL:** `https://www.successchemistry.com/feeds/google-shopping` (redirects to `/api/feeds/google-shopping`) or use `https://www.successchemistry.com/api/feeds/google-shopping` directly.
- **Generated by:** `src/app/api/feeds/google-shopping/route.ts` (dynamic XML from `TOP_PRODUCTS`)
- **Format:** RSS 2.0 with Google Base (`g:`) namespace – id, title, description, link, image_link, price, availability (`in_stock`), brand, condition, google_product_category, gtin or (identifier_exists + mpn), additional_image_link, custom_label_0–2, consumer_notice. All URLs use HTTPS; HTML is stripped from title/description.
- **Use for:** Google Merchant Center product feed so Shopping ads and free listings use SCV2 product data and tracking.

### Do you need a new feed for tracking?

- **For Google Shopping / Merchant Center:** Use the **new** feed above. Point Merchant Center to `https://www.successchemistry.com/feeds/google-shopping` (or your production domain). This feed is built from the same `TOP_PRODUCTS` as the site, so it stays in sync.
- **For general SEO:** The **sitemap** is enough; no separate feed is required for search indexing.

### Setup in Merchant Center

1. [Merchant Center](https://merchants.google.com) → **Products** → **Feeds**.
2. Add feed (or edit existing) → **Primary** or **Supplemental**.
3. **Input method:** “Scheduled fetch”.
4. **File URL:** Use the **exact** URL where this site is live (e.g. `https://www.successchemistry.com/feeds/google-shopping` or `https://YOUR-PROJECT.vercel.app/feeds/google-shopping`).
5. **Fetch schedule:** e.g. daily.
6. Save; wait for processing. Fix any product errors Merchant Center reports.

**If Merchant Center says "File not found":** The feed URL must match your live deployment’s domain. Open the feed URL in a browser—you should see XML. If you see 404, deploy the latest code and use that deployment’s base URL + `/feeds/google-shopping`.
