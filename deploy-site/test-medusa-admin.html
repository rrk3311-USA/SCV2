1. Open Medusa Admin

When Medusa is running locally, the admin is at http://localhost:7001. Click below to open it.

Open Medusa Admin →

If the link doesn’t load, start Medusa first (step 2).

2. Run Medusa locally (one-time)

From the project root, in a separate folder:

npx create-medusa-app@latest --with-nextjs-starter

Pick a folder name (e.g. medusa-test). When it finishes, run the backend and open the admin from the project’s README (or start backend + admin; admin is usually on port 7001).

Or, if you already have a Medusa project:

cd your-medusa-folder
npm run dev

Backend: localhost:9000, Admin: localhost:7001. First time you open Admin you’ll create an admin user.

3. What you get

Medusa Admin gives you: products, orders, customers, settings, and API. No payment to Medusa — the app is open source; you only pay for hosting if you deploy it.

This page is just a launcher and instructions. The actual admin runs in its own app at http://localhost:7001 (or your deployed admin URL).
